# نقا | NUQA
مجلد مستقل لموقع نقا داخل مستودع Myser، ولا يغير تطبيق Myser.

موقع تجريبي متجاوب للنظافة الذكية، بهوية كحلية وتركوازية، وشعار العرض الأصلي المعروض من الصورة المضمّنة في ملف NUQA_English.pptx.

## فتح الموقع
افتح نسخة HTML المستقلة (nuqa-updated.html) مباشرة بالمتصفح؛ تشمل الصور والخطوط والترجمات والشيفرة دون اتصال خارجي. حفظ البيانات محليًا يعتمد على دعم المتصفح لملفات HTML المحلية؛ عند منع التخزين تبقى التجربة عاملة مؤقتًا.

لتشغيل ملفات المصدر:
```sh
cd nuqa
python3 -m http.server 3001 --bind 0.0.0.0
```
ثم افتح http://localhost:3001 . لا توجد حزم تشغيل أو عملية بناء مطلوبة.

## الواجهات
- يبدأ كل فتح للموقع بشاشة اختيار الصفة: موظف المراقبة، عامل النظافة، فرد. تخصيص العرض تجريبي ولا يمثل نظام حسابات أو صلاحيات أمنية.
- الفرد: إنشاء البلاغ بصورة للمعاينة وموقع ووصف، ومتابعة الحالات. لا يغير حالة البلاغ.
- العامل: استلام المهمة وبدء المعالجة ثم تأكيد الإنجاز لإرسال الحالة إلى انتظار المراجعة.
- الموظف: مراجعة أحداث رصد الحاويات، إسناد الحالات للمعالجة، والتحقق من إنجاز العامل قبل الإغلاق؛ ومحاكاة رصد المركبات.
- المركبات: ثماني سيارات متحركة بلوحات افتراضية DEMO-001 إلى DEMO-008. زر محاكاة رمي نفايات يعرض الحدث ويسجل مخالفة تجريبية على لوحة السيارة محليًا، مرة واحدة لكل سيارة. لا توجد قراءة لوحات أو تحليل فيديو أو غرامات فعلية.

## اللغات والخطوط
27 لغة: العربية، الإنجليزية، الفرنسية، الإسبانية، الألمانية، الإيطالية، البرتغالية، الروسية، التركية، الصينية، اليابانية، الكورية، الهندية، الأردية، البنغالية، الإندونيسية، الملايوية، الفارسية، السواحيلية، الفلبينية، التاميلية، التيلوغوية، المالايالامية، التايلاندية، الفيتنامية، الهولندية، البولندية.

84 نصًا محليًا لكل لغة، تشمل الحقول والأزرار والحالات والتنبيهات وواجهات الأدوار. تغيير الاتجاه للعربية والأردية والفارسية وحفظ الاختيار محليًا. بيانات المستخدم ومعرّفات الحالات واللوحات لا تترجم. خطوط Noto Sans Arabic وDM Sans، مع خطوط Noto للنصوص الأخرى مضمّنة محليًا وتراخيصها داخل assets.

## البيانات
البلاغات والمخالفات في localStorage بهذا المتصفح؛ لا يُرسل شيء إلى جهة فعلية. الصور للمعاينة فقط ولا تحفظ. مشاهد الرصد والمركبات مرسومة، والمربعات والأحداث محددة مسبقًا. صورة الرياض تصورية. نصوص اللغة قابلة للتحرير في tools/locales.py وتُولّد إلى translations.js.

## التحقق والتغليف
tools/check_site.py يختبر اللغات الـ27 واتجاه النص والجوال والأدوار والبلاغات ومسار العمل والتنبيهات والمركبات عبر Playwright وChromium. tools/package_site.py ينتج نسخة HTML مستقلة وZIP من الملفات الجاهزة للتشغيل.
